# 순천향 캠퍼스 길찾기

지금 위치에서 순천향대학교(아산) 캠퍼스 건물까지 **걸어가는 길과 시간**을 알려주는 모바일 웹입니다.

**👉 https://sch-campus-nav.vercel.app** (폰에서 열고 위치 권한을 허용하세요)

카카오맵·네이버지도는 캠퍼스 안 보행로와 건물 출입구를 잘 모릅니다. 그래서 큰길로 돌아가라고 하거나, 건물 뒤편 엉뚱한 쪽으로 안내합니다.
이 앱은 캠퍼스 보행로와 **실제 출입구 46곳**을 직접 조사해서, 재학생이 실제로 다니는 길로 안내합니다.

## 할 수 있는 것

- **현재 위치에서 출발** — 건물 안에 있으면 그 건물에서 출발합니다. 건물 안 어디에 있든 목적지에 가장 빠른 문을 골라 "북측문으로 나가기"처럼 알려줍니다.
- **목적지 검색** — 강의실 코드(`U524`, `9115`, `공학관305`), 건물 이름(`공학관`), 이름 일부(`BRIX`, `미디어랩스`), 학생들이 쓰는 줄임말(`향2`, `글빌`, `교식`, `미랩`)을 받습니다.
- **건물 관통 지름길** — 유니토피아관·향설생활관1·향설생활관2처럼 1층을 통과할 수 있는 건물은 통과해서 갑니다. 이때 일반 길(회색 점선)과 몇 분 차이인지 같이 보여줍니다.
- **언덕 반영** — 산길계단·비탈길은 오르막과 내리막 시간을 따로 계산합니다.
- **단계별 안내·로드뷰** — 꺾이는 곳마다 안내하고, 도착 건물의 로드뷰 사진을 보여줍니다.
- **자주 가는 곳** — 첫 화면에서 도서관·학생회관·식당 등까지 지금 몇 분인지 보여줍니다.

## 한계 (솔직하게)

- **건물 문 앞까지 안내합니다.** 강의실 코드를 넣으면 층은 알려주지만, 건물 안의 계단·복도 안내는 아직 없습니다.
- **예상 시간은 계산값입니다.** 평지·계단·오르막 속도를 정해 놓고 계산한 값이며, 실제로 걸어서 맞춰 본 것은 아닙니다.
- 출입구 46곳 중 7곳은 로드뷰가 닿지 않아 위성 사진으로만 찍었습니다 (`data/doors.json` 의 `confirmed: false`).
- 밤·주말에 잠기는 건물도 지름길로 안내합니다.

## 실행하기

필요한 것: Node.js 24 이상, (데이터를 다시 만들 때만) Python 3

```bash
npm install
cp .env.example .env      # VITE_KAKAO_JS_KEY 에 카카오 JavaScript 키를 넣는다
npm run dev               # http://localhost:5173
```

카카오 개발자센터 → 내 애플리케이션 → 앱 키 → JavaScript 키 → **JavaScript SDK 도메인**에 `http://localhost:5173` 을 등록해야 지도가 뜹니다. 포트는 5173 으로 고정돼 있습니다.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm test` | 단위 테스트 (강의실 코드 해석, 경로 탐색, 현재 위치 출발, 안내 문구) |
| `npm run graph` | `data/` 의 원본으로 보행 그래프(`outdoor-graph.json`)를 다시 만들고 경로 규칙을 검사 |
| `npm run check:routes` | 경로 규칙만 검사 — "공학관 → 미랩은 산길계단으로 내려간다" 같은 재학생 확인 사항 16개 |
| `npm run build` | 배포용 빌드 (`dist/`) |

개발 서버에서만 열리는 화면: `/?edit` 출입구 찍는 도구, `/?gl` MapLibre 실험 지도. 배포본에는 들어가지 않습니다.

## 어떻게 동작하나

```
OpenStreetMap 보행로 ─┐
조사한 출입구 46곳 ────┤                       ┌─ 다익스트라 최단 경로 (브라우저)
손으로 넣은 길·지름길 ─┼─ tools/extract_paths.py ─┤
경사·막힌 길 ─────────┘    → outdoor-graph.json  └─ 카카오맵 위에 그리기
```

- **보행 그래프**: OSM 보행로에 조사한 출입구, 재학생이 알려준 길(산길계단, 걷고싶은 길 등), 건물 관통 구간을 더해 만듭니다. 노드는 수백 개라 서버 없이 브라우저에서 바로 계산합니다.
- **출입구**: OSM 에는 캠퍼스 출입구 정보가 없습니다. 카카오 로드뷰에서 문이 보이는 방향을 여러 촬영 지점에서 읽고, 그 방향선이 만나는 곳으로 위치를 잡았습니다. 근거는 `data/door-evidence.json` 에 남겨 두었습니다.
- **건물 허브 통과 금지**: 건물 대표점은 출발·도착에만 씁니다. 그래야 "통과할 수 있는지 모르는 건물을 가로지르는" 경로가 안 나옵니다. 실제로 통과할 수 있는 곳만 `data/shortcuts.json` 에 넣습니다.

### 폴더

```
src/App.tsx            화면 (검색 카드, 바텀시트, 지도 그리기)
src/lib/graph.ts       최단 경로 탐색
src/lib/campus.ts      데이터 묶기, 건물/현재 위치 출발, 나갈 문 고르기
src/lib/roomCode.ts    강의실 코드·건물 이름 해석
src/lib/steps.ts       단계별 안내 문구
data/                  건물·출입구·보행로 원본과 생성된 그래프 (각 파일 맨 위 _what/_why 에 설명)
tools/                 데이터 만들기·검사 스크립트
```

도구 스크립트가 만드는 스크린샷 같은 중간 파일은 `tmp/` (또는 환경변수 `OUT_DIR`)에 쌓이고 레포에는 올라가지 않습니다.
